# GH-900: GitHub Foundations — Study Guide

Personal study guide aligned to the [official GH-900 skills measured](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-900) (as of **January 2026**; page last updated **February 19, 2026**).

## How to use this guide

GH-900 tests **GitHub as a platform**, not just `git` commands. If you already use Git day-to-day, skim Domain 1 vocabulary and spend most time on **collaboration, Actions/Copilot/Codespaces, security/admin, Projects, and community**.

| Priority | Area | Weight | Why |
|----------|------|--------|-----|
| High | Git & GitHub basics (concepts + GitHub Flow) | 25–30% | Largest domain; exam wording matters |
| High | Collaborate (issues, PRs, discussions) | 10–15% | Core “how work happens on GitHub” |
| High | Modern practices (Actions, Copilot, Codespaces) | 10–15% | Newer objectives; easy to understudy |
| High | Privacy, security, administration | 10–15% | Permissions, 2FA, branch protection, EMUs |
| Medium | Repositories (structure, key files, insights) | 10–15% | README/LICENSE/CODEOWNERS etc. |
| Medium | Projects | 5–10% | Boards, labels, milestones, insights |
| Medium | Community (OSS, Sponsors, InnerSource, Marketplace) | 5–10% | Short but distinct |

**Passing score:** 700 / 1000 (scaled)  
**Official practice:** [GitHub Foundations practice assessment](https://learn.microsoft.com/en-us/credentials/certifications/github-foundations/)  
**Exam env:** [exam sandbox](https://aka.ms/examsandbox)
