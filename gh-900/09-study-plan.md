# Suggested study plan (GH-900)

If you already use Git regularly, compress Day 1 and invest in Days 3–6 (collaboration, modern tools, security, community).

Target: **~8–12 hours**, or about **1–2 weeks** part-time.

---

## Day 1 — Git & GitHub basics (≈ 1.5–2 hr)

- Read [01-git-github-basics.md](./01-git-github-basics.md)
- Drill: Git vs GitHub, commits/branches/remotes, **GitHub Flow**, Markdown, Desktop vs Mobile, accounts/orgs/enterprise
- Optional: Microsoft Learn GitHub Foundations Part 1 (modules covering intro)

**Hands-on:** Create a branch → commit → open PR → merge on a throwaway repo

---

## Day 2 — Repositories (≈ 1–1.5 hr)

- Read [02-repositories.md](./02-repositories.md)
- Drill: README, LICENSE, CONTRIBUTING, CODEOWNERS, SECURITY, templates, insights
- Add a CODEOWNERS and SECURITY.md to a practice repo (even stub content)

---

## Day 3 — Collaboration (≈ 1.5–2 hr) — priority

- Read [03-collaboration.md](./03-collaboration.md)
- Drill: Issues vs PRs vs Discussions; linking with `Fixes #`; notifications; Gists / Wikis / Pages
- Practice: issue template, draft PR, request review, link `Closes #n`

---

## Day 4 — Modern development (≈ 2 hr) — priority

- Read [04-modern-development.md](./04-modern-development.md)
- Drill: Actions vocabulary (workflow/job/step/runner); Copilot tiers + agents; Codespaces + dev containers; github.dev vs Codespaces
- Hands-on ideas:
  - Add a simple Actions workflow (e.g. run on `push`)
  - Open a repo with `.` (github.dev) once
  - Skim Copilot plan comparison on GitHub docs

---

## Day 5 — Projects + security/admin (≈ 2–2.5 hr) — priority

- Read [05-projects.md](./05-projects.md) and [06-privacy-security-admin.md](./06-privacy-security-admin.md)
- Drill: Projects layouts, labels, milestones, saved replies, project insights
- Drill: 2FA/passkeys, repo roles, orgs/teams, visibility, branch protection, EMUs, Dependabot/secret scanning *purpose*
- Hands-on: enable a basic branch protection rule on a test repo’s `main`

---

## Day 6 — Community + cram (≈ 1.5–2 hr)

- Read [07-community.md](./07-community.md)
- Drill: OSS benefits, Sponsors, Marketplace, InnerSource, fork vs template, follow vs star
- Walk [08-quick-reference.md](./08-quick-reference.md) cold
- Take Microsoft’s **free Practice Assessment** for GitHub Foundations
- Re-read only weak domains

Aim for practice scores consistently **≥ ~80%** before scheduling.

---

## What to under-study (on purpose)

- Memorizing every `git` flag  
- Writing complex Actions pipelines from scratch  
- Deep CodeQL / advanced enterprise SSO configuration  
- Pixel-perfect Projects automation recipes  

## What must be automatic

1. Git vs GitHub  
2. GitHub Flow steps  
3. Issue / PR / Discussion  
4. Actions vs Copilot vs Codespaces vs github.dev  
5. Key community files (LICENSE, CONTRIBUTING, CODEOWNERS, SECURITY)  
6. Branch protection purpose  
7. Repo permission ladder  
8. Fork vs template; InnerSource vs public OSS  
9. Sponsors vs Marketplace  
10. EMUs and org Copilot policy at a conceptual level
