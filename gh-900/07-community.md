# Domain 7: Explore the GitHub community (5–10%)

Short domain — memorize definitions and “when to use” cues.

---

## Open source and GitHub Sponsors

### Benefits of open source

- Transparency and trust  
- Community contributions and faster innovation  
- Reuse of libraries/tools  
- Learning and portfolio building  
- Industry standards and interoperability  

GitHub is a major host for public OSS collaboration (issues, PRs, Discussions, Actions, security advisories).

### GitHub Sponsors

- Way for individuals/orgs to **financially support** maintainers and projects  
- FUNDING.yml / Sponsors button discoverability  

**Exam:** Sponsors = funding maintainers; Marketplace = apps/actions to install (below).

---

## How GitHub advances OSS

Examples the exam may imply:

- Discoverability (search, topics, trending, stars)  
- Collaboration tools (issues, PRs, Discussions)  
- Security features for public repos  
- Social proof and community norms (CODE_OF_CONDUCT, good first issue)  
- GitHub Sponsors and open-source program resources  

---

## Following users and organizations

- **Follow** people/orgs to see activity in your feed / stay informed  
- **Watch** / star repos for project-level signals (related but different)  

**Exam:** Follow = people/orgs; Star/Watch = repositories.

---

## GitHub Marketplace

- Catalog of **Apps** and **Actions** that extend GitHub  
- Install CI tools, chat ops, project automation, security scanners, etc.  

**Exam cue:** “Find a third-party Action or App to add to the org/repo” → Marketplace.

---

## InnerSource

Apply **open-source practices inside a company**:

- Internal “public” (or discoverable) repos  
- Cross-team PRs and CONTRIBUTING culture  
- Shared ownership, documentation, discoverability  

**Not** the same as publishing to the internet — it’s OSS *process* for private/enterprise codebases.

---

## Forks, templates, discoverable repos

| Approach | Use when |
|----------|----------|
| **Fork** | Copy a repo to contribute upstream or customize with lineage to original |
| **Template** | Start a **new** project from a curated starter (no fork relationship required) |
| **Discoverable repos** | Topics, README, public/internal visibility so others can find and reuse |

**Exam traps:** Fork ≠ Template. InnerSource ≠ open-sourcing to the world.
